# What Gets Installed

Twinbox sets up a full Kubernetes platform rather than a single app.
This chapter gives readers the big picture so they understand why the wizard
asks for so many decisions.

## Included by default

- Talos Linux
- Cilium
- Argo CD
- Longhorn
- OpenBao and External Secrets Operator
- Traefik
- Velero
- CloudNativePG
- Twinbox Portal
