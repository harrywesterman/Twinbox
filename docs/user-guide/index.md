# Start Here

This guide is for people who want to use Twinbox as a product, not study the
implementation first.

## The flow

1. Prepare a Proxmox host and decide where the Management VM should live.
2. Run the bootstrap step that creates the Management VM.
3. Open the web wizard inside the Management VM and finish the cluster setup.
4. Review the installed platform so you know what is running where.
