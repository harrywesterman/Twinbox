# Twinbox User Guide

Twinbox turns a Proxmox host into a Talos-based Kubernetes cluster with a guided
management flow. This site gives you two paths:

- a short user guide with screenshots and practical steps
- a technical reference for the underlying platform and scripts

If you are just starting, follow the user guide in order. If you already know
your way around Twinbox, jump straight to the technical reference.

## Start here

1. Read [Before you begin](user-guide/getting-started.md) to check what you need.
2. Follow [Proxmox bootstrap](user-guide/bootstrap.md) to create the Management VM.
3. Continue with [Web wizard](user-guide/web-wizard.md) inside the browser.
4. Review [What gets installed](user-guide/platform.md) to understand the final stack.
