# Beszel Monitoring Integration for Twinbox

## Overzicht

Integreer [Beszel](https://beszel.dev) (lichtgewicht server monitoring met Docker stats, historische data, alerts) in Twinbox.

Beszel heeft twee componenten:
- **Hub** — PocketBase web dashboard (draait op Management VM)
- **Agent** — Lichtgewicht Go binary per host (Management VM + K8s nodes)

Keuzes gemaakt met @harrywesterman:
- ✅ **Zero-config** (Optie B): geen per-app YAML — Beszel ontdekt alle containers automatisch via Docker/containerd sockets
- ✅ **Authentik OIDC** voor hub authenticatie
- ✅ **Geen `privileged: true`** — alleen `hostNetwork`, `hostPID`, en volume mounts
- ✅ containerd socket pad: `/run/containerd/containerd.sock` (Talos)
- ⏳ Backup naar SeaweedFS: later

## Fase 1 — Hub + Agent op Management VM

### `config/pinned-defaults.sh`

Voeg pinned versie toe:

```bash
BESZEL_VERSION=0.18.7
```

### `docker-compose.yml`

Voeg twee services toe:

**`beszel`** (hub):
- Image: `henrygd/beszel:${BESZEL_VERSION:-0.18.7}`
- Container name: `twinbox-beszel`
- Restart: `unless-stopped`
- Environment:
  - `APP_URL=https://beszel.__ZONE_NAME__`
  - `BESZEL_OIDC_ENABLED=true`
  - `BESZEL_OIDC_PROVIDER_URL=${BESZEL_OIDC_PROVIDER_URL}`  — van Authentik
  - `BESZEL_OIDC_CLIENT_ID=${BESZEL_OIDC_CLIENT_ID}`
  - `BESZEL_OIDC_CLIENT_SECRET=${BESZEL_OIDC_CLIENT_SECRET}`
  - `BESZEL_AUTH_DISABLE_PASSWORD=true`
- Ports: `8090:8090`
- Volumes:
  - `/opt/twinbox/beszel/data:/beszel_data`
  - `/opt/twinbox/beszel/socket:/beszel_socket`

**`beszel-agent`** (local agent voor Management VM):
- Image: `henrygd/beszel-agent:${BESZEL_VERSION:-0.18.7}`
- Container name: `twinbox-beszel-agent`
- Restart: `unless-stopped`
- Network mode: `host`
- Volumes:
  - `/opt/twinbox/beszel/agent-data:/var/lib/beszel-agent`
  - `/opt/twinbox/beszel/socket:/beszel_socket`
  - `/var/run/docker.sock:/var/run/docker.sock:ro`
- Environment:
  - `LISTEN=/beszel_socket/beszel.sock`
  - `HUB_URL=http://localhost:8090`
  - `KEY="${BESZEL_AGENT_KEY}"`
  - `TOKEN=${BESZEL_AGENT_TOKEN}`
- Depends on: `beszel`

### Nieuwe env vars

```
BESZEL_AGENT_KEY=<auto-generated ed25519 public key>
BESZEL_AGENT_TOKEN=<auto-generated hex token>
BESZEL_OIDC_PROVIDER_URL=https://authentik.<zone>/application/o/beszel/
BESZEL_OIDC_CLIENT_ID=<uit Authentik>
BESZEL_OIDC_CLIENT_SECRET=<uit Authentik>
```

### Authentik OIDC config

Maak een Authentik provider aan voor Beszel:
- Provider type: OAuth2/OpenID
- Client type: Confidential
- Redirect URIs: `https://beszel.<zone>/oauth/callback`
- Signing key: any
- Subject mode: Based on User ID (hashed)

## Fase 2 — Agent DaemonSet op K8s Cluster

### Namespace: `beszel`

Pod security: `privileged` (noodzakelijk voor `hostPID: true`).

### DaemonSet config

```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: beszel-agent
  namespace: beszel
spec:
  selector:
    matchLabels:
      app.kubernetes.io/name: beszel-agent
  template:
    metadata:
      labels:
        app.kubernetes.io/name: beszel-agent
    spec:
      hostNetwork: true
      hostPID: true
      dnsPolicy: ClusterFirstWithHostNet
      containers:
        - name: agent
          image: henrygd/beszel-agent:0.18.7
          env:
            - name: HUB_URL
              value: "https://beszel.__ZONE_NAME__"
            - name: KEY
              valueFrom:
                secretKeyRef:
                  name: beszel-agent-credentials
                  key: key
            - name: TOKEN
              valueFrom:
                secretKeyRef:
                  name: beszel-agent-credentials
                  key: token
            - name: CONTAINER_RUNTIME
              value: "containerd"
          volumeMounts:
            - name: containerd-sock
              mountPath: /run/containerd/containerd.sock
              readOnly: true
            - name: agent-data
              mountPath: /var/lib/beszel-agent
          securityContext:
            readOnlyRootFilesystem: true
            allowPrivilegeEscalation: false
            capabilities:
              drop:
                - ALL
      volumes:
        - name: containerd-sock
          hostPath:
            path: /run/containerd/containerd.sock
        - name: agent-data
          hostPath:
            path: /var/lib/beszel-agent
            type: DirectoryOrCreate
```

**Geen `privileged: true`** — alleen `hostNetwork: true` + `hostPID: true` + read-only mounts. Capabilities worden gedropt, `readOnlyRootFilesystem: true`, `allowPrivilegeEscalation: false`.

### Waarom `hostPID: true`?

Beszel agent leest `/proc` voor CPU/memory/disk metrics van de host. Zonder `hostPID: true` ziet de container alleen zijn eigen cgroup-gefilterde `/proc`. Met `hostPID: true` kan de agent host-level metrics verzamelen.

Risico is laag: read-only toegang tot process IDs. Geen netwerk capabilities, geen device access, geen `privileged: true`. Vergelijk: NetBird routing peers draaien met `privileged: true` + `NET_ADMIN` + `SYS_ADMIN`.

### Waarom `hostNetwork: true`?

Voor network interface metrics (bandwidth, connections). Cilium DaemonSet gebruikt dit ook.

### ExternalSecret

Haalt `key` en `token` uit OpenBao (ge-sync via `sync-openbao-global-secret.sh`).

## Fase 3 — Wizard Step

### `categories/talos-cluster/steps/install-beszel/step.yaml`

```yaml
id: install-beszel
title: Install Beszel Monitoring
type: action
journey_stage: manage
summary: Lightweight server monitoring with Docker stats, historical data, and alerts.
explanation: >
  Beszel monitors your Management VM and all Kubernetes cluster nodes.
  It tracks CPU, memory, disk, network, and container usage with a
  lightweight agent — no public internet exposure required.
  Configure alerts for CPU, memory, disk, and system status in the
  Beszel dashboard.
side_help: >
  Beszel uses a hub-and-agent architecture. The hub runs on the Management VM
  and provides a web dashboard with OIDC login via Authentik. A local agent
  monitors the Management VM itself, and a DaemonSet on the cluster monitors
  all Kubernetes nodes.
dashy:
  items:
    - section: Platform
      title: Beszel
      description: Server monitoring dashboard
      icon: fas fa-heartbeat
      url_template: https://beszel.__ZONE_NAME__
inputs: []
secrets:
  files:
    KUBECONFIG_FILE:
      scope: cluster
      item: kubeconfig
      attachment: kubeconfig
      format: file
runner:
  kind: script
  script: categories/talos-cluster/steps/install-beszel/run.sh
```

### `categories/talos-cluster/steps/install-beszel/run.sh`

Het script doet:

1. **Keys genereren** (indien nog niet bestaan)
   - `BESZEL_AGENT_KEY` = ed25519 public key
   - `BESZEL_AGENT_TOKEN` = `openssl rand -hex 32`
   - Opslaan in OpenBao via `sync-openbao-global-secret.sh`

2. **OIDC secrets ophalen** uit OpenBao (Authentik client ID/secret)

3. **`/opt/twinbox/.env` aanvullen** met `BESZEL_AGENT_KEY`, `BESZEL_AGENT_TOKEN`, OIDC vars

4. **Docker compose starten** — de nieuwe services worden opgepikt:
   ```bash
   docker compose up -d
   ```

5. **Wachten op hub health**:
   ```bash
   for i in $(seq 1 30); do
     if curl -sf http://localhost:8090/api/health >/dev/null 2>&1; then break; fi
     sleep 2
   done
   ```

6. **NetBird service registreren**:
   ```bash
   bash "$WORKSPACE_ROOT/scripts/manager/ensure-netbird-service.sh" \
     --service-name beszel \
     --service-domain "beszel.$(cluster_public_zone)"
   ```

7. **Argo CD Application deployen** voor de DaemonSet:
   ```bash
   bash "$WORKSPACE_ROOT/scripts/manager/apply-argocd-application.sh" \
     --app-name beszel-agents \
     --app-path gitops/platform-apps/beszel-agents \
     --namespace beszel
   ```

## Veiligheidsoverwegingen

| Aspect | Status |
|--------|--------|
| Container `privileged: true` | ❌ Niet gebruikt |
| `hostPID: true` | ✅ Alleen read-only process list |
| `hostNetwork: true` | ✅ Alleen network metrics lezen |
| Capabilities | ✅ `drop: [ALL]` |
| `readOnlyRootFilesystem` | ✅ `true` |
| `allowPrivilegeEscalation` | ✅ `false` |
| Namespace pod security | `privileged` (noodzakelijk voor `hostPID`) |
| OIDC | ✅ Authentik, wachtwoord auth disabled |
| Data encryptie | Disk-only (later SeaweedFS backup) |
