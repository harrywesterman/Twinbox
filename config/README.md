# config/

Pinned default versions and settings used across Twinbox provisioning scripts.

## Files

- `pinned-defaults.sh` — shell variables for tool and chart versions (Talos, OpenTofu, k9s, kubectl, helm, External Secrets, OpenBao) and Proxmox image defaults.
- `cilium-values.yaml` — Helm values for the Cilium CNI bootstrap manifest.
- `portal/` — Portal-specific configuration files (themes, default apps, layout templates).
