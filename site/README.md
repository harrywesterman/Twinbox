# Site

Static landing page for Twinbox.

## Overview

A minimal static HTML/CSS landing page that can be served independently or as a fallback page.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Static HTML landing page |
| `styles.css` | Stylesheet for the landing page |

## Usage

These files are typically served by a simple web server or embedded in a container image for static hosting.

## Related

- The main Twinbox Portal lives in `portal/`
- This directory may be used for a public-facing status or landing page
